# Сообщения: привычная навигация мессенджера

Полный профиль, действия с контактом и уточнение доставки первого сообщения: [актуальный сценарий](person-profile.md). Из поиска/контактов/заголовка открывается один экран профиля. Новая регистрация автоматически подготавливает переписку под единственным ключом аккаунта.

16 октября 2026. Этот сценарий заменяет экран, на котором одновременно показывались две панели вкладок, настройки защиты и кнопки действий под каждым сообщением.

Главный экран — список переписок. В строке: аватар с инициалами, имя, последнее доступное сообщение, время и счётчик непрочитанных. Последние активные переписки находятся сверху. Удалённые, скрытые и очищенные сообщения в превью не попадают; исходный текст расшифровывается только клиентом и не сохраняется в новом plaintext cache.

Плюс справа открывает «Новое сообщение». Ввод публичного ID или @username автоматически ищет человека на сервере и показывает карточку: доступное имя, @username, публичный ID, разрешённые анкетой поля, «Написать» и «Аудиозвонок». Username без @ также принимается; имя фильтрует сохранённые контакты, выбор строки открывает такую же карточку. До получения результата кнопки отправки незнакомому пользователю нет. Поиск и открытие чата имеют отдельные состояния; после ошибки карточка остаётся, действие можно повторить. Недоступность звонков или сообщений объясняется рядом с действиями. Изменение запроса/аккаунта, закрытие карточки и уход со страницы отменяют публикацию устаревшего результата.

Человек может написать без предварительного обмена контактами. Создание чата заново проверяет адресата через Identity boundary и не зависит от обновления всего списка контактов. Повторное обращение открывает существующий личный чат, возвращая его из архива. Окно закрывается после получения комнаты SDK; таймаут не объявляется успешным открытием. Аудиозвонок из карточки открывает этот же чат и запускает существующий MatrixRTC flow. Отказ микрофона показывается явно.

Создание группы и добавление контакта — отдельные действия. Контакты открываются отдельной кнопкой, архив появляется в одной строке фильтров при наличии таких чатов. Нет второго ряда «Переписки/Контакты» и постоянного блока об успешной настройке шифрования.

На узком экране открыт либо список, либо чат. В чате dock скрыт, назад возвращает список; строка ввода остаётся в нижней части доступного viewport. На широком экране список и переписка видны рядом. Установка PWA, keyboard/safe area на физических iPhone/Android остаются отдельной mobile-приёмкой; desktop engines не подменяют эту проверку.

В переписке: разделители дат, группировка соседних сообщений, компактное время и галочки доставки/прочтения. Имя автора показывается в группе, не повторяется в каждом входящем сообщении личного чата. Короткая переписка располагается у строки ввода. Старые сообщения загружаются при прокрутке вверх с сохранением позиции. Входящие сообщения не принуждают пользователя прокручивать вниз во время чтения истории; есть кнопка перехода к последним.

Удержание сообщения на touch, context menu или Enter на сфокусированном сообщении открывает ответ, копирование, закрепление/открепление, выбор и удаление. Для mouse также доступна кнопка при наведении. Свайп сообщения вправо готовит ответ. Постоянных «Закрепить», «Ответить» и технических текстов доставки под каждой репликой нет. Закреплённая полоса переносит к сообщению и не заменяет всю историю фильтром.

Поиск внутри чата раскрывается по кнопке в заголовке. Глобальный поиск объединяет фильтр чатов и поиск доступной E2EE истории; новый запрос отменяет публикацию результатов прежнего. Выбор сообщений открывается через меню чата или сообщения: можно выбрать все, удалить у себя, а при разрешённых правах — у всех, с отдельным подтверждением. В личном чате это доступно для своих и входящих сообщений. Групповые права проверяются Matrix и отражаются в доступных действиях.

Черновики сохраняются между чатами в памяти текущего открытого раздела. Нового plaintext IndexedDB/localStorage для сообщений и черновиков нет. При смене аккаунта и закрытии раздела память очищается. Desktop Enter отправляет сообщение, Shift+Enter добавляет строку; на touch Enter оставляет перенос строки. Не обещается холодная offline-история, которой SDK-интеграция пока не предоставляет.

Локальный Matrix ID собеседника разрешается через существующий Identity boundary в публичный/доступный профиль. Приватные поля и блокировки продолжают применяться. Технический `@pb_…:server` не используется как обычное имя человека. Это не добавляет контакт без согласия и не публикует приватный nickname в Matrix state.

Проверки: `check-messenger-ui.mjs` — обе компоновки, 320/390/768/1440, короткая переписка, удержание/ответ, закрепление, поиск, удаление входящего у обоих и черновик. `check-messenger-actions.mjs` — полный поиск истории, архив и восстановление, выбор всех, удаление переписки у обоих, синхронизация контактов. `check-messages.mjs` сохраняет group/SAS/recovery/revocation coverage. Скриншоты QA содержат только синтетические имена и сообщения.

При исходной переработке: 103 API tests / 1478 assertions, 135 client tests, TypeScript/Vite build. Новый UI, messenger actions и single-account-key recovery проверены Chromium/WebKit. Полный B02 group/SAS/recovery/revocation/account-switch сценарий прошёл Chromium и повторный WebKit прогон. Дополнительно проверены сохранение позиции истории при позднем ACK/входящем сообщении и simulated visualViewport height для клавиатуры. Физические installed-PWA iPhone/Android остаются R01.

Уточнение поиска человека: 142 client tests и TypeScript; `check-messenger-ui.mjs` в Chromium/WebKit проверяет публичный ID, @username и локальный Matrix ID, отсутствие результата для своего/несуществующего ID, карточку с действиями и повторное открытие той же комнаты. Дополнительные проверки повторяют поиск и открытие после сетевой ошибки и запускают аудиозвонок из карточки с синтетическим отказом микрофона. Это проверка запуска и сообщения об отказе, не приёмка реального медиазвонка на телефоне.

17 октября: запросы на переписку и принятие контактов удалены. После «Написать» получатель присоединяется автоматически до отправки первого сообщения. Старые входящие переписки подключаются автоматически на проверенном устройстве. Контакт — личная запись владельца, синхронизируемая между его устройствами. Добавление не открывает чужие закрытые поля. Голосовые: удержание/отпускание, свайп отмены и фиксации, пауза, предпрослушивание, отправка; проигрыватель с перемоткой и скоростью. Детали хранения и шифрования: ADR 0016.

Проверка 17 октября: первое сообщение холодному адресату, полный профиль, личные контакты, ошибки открытия/повтор и messenger actions прошли Chromium/WebKit. Голосовые прошли запись/предпрослушивание, остановку микрофона, E2EE upload/receive/playback/speed, отмену слайдом, отказ разрешения, паузу, повтор после сбоя upload и удаление входящего у всех. Используется синтетический аудиопоток; испытания физических телефонов остаются R01.
