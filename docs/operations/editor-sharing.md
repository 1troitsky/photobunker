# B05 — Редактор, зашифрованные версии, приватные ссылки

Путь: Фото → открыть снимок → Редактировать. Доступны crop/rotate/mirror, цвет, кисть/карандаш/ластик, размещаемые текстовые слои, прямоугольник/эллипс, undo/redo. Вкладка «Приватность»: провести по закрываемой области; добавить водяной знак. «Сохранить версию» не изменяет оригинал. В «Версиях» видны облачный статус, ожидающая отправки локальная версия и параллельные работы; повторная синхронизация доступна явно. Открытие снимка также повторяет отправку ожидающих версий. Уже открытый редактор позволяет сохранить работу при потере сети; показывает локальное сохранение и сохраняет проверку несохранённых новых правок. Недоступная выбранная версия не заменяется оригиналом при просмотре, редактировании или передаче.

Версии сохраняются неизменяемыми: параллельное сохранение оставляет обе работы. Для редактирования прежней версии сохраняются её слои в координатах исходного снимка. Каждый результат и manifest зашифрованы независимо, с привязкой к родителю/UUID/kind, подписаны ключом устройства. Локальный pending draft — только ciphertext; сервер ACK не выдаётся до записи обоих объектов. Истёкшее/удалённое фото, чужой аккаунт, изменение разрешений, недостаток квоты останавливают публикацию. TTL каждой версии ограничен оригиналом. До отправки родительского снимка версия остаётся локальной.

«Поделиться» показывает очищенный файл выбранной версии. Для облачного зашифрованного снимка доступны приватная ссылка, срок 1 час/сутки/7 дней в пределах TTL, просмотр либо просмотр и скачивание, отзыв своих ссылок. Получатель открывает `/s/<random-id>#<secret>` без аккаунта; это единственное публичное представление и в нём нет Dock, ссылок на профиль или переходов в приложение. Ключ находится только после `#`, удаляется из адреса после открытия и не отправляется API. После обновления страницы нужно вновь открыть полную ссылку. Издатель копирует полную ссылку при создании: после закрытия sheet можно отозвать старую или создать новую; сервер не хранит её секрет. Сервис получает независимый ciphertext экспорта, случайный IV и технический manifest; оригинал, edit layers, EXIF, автор, пресет, команда и GPS в него не входят. Подробности протокола: [ADR 0011](../adr/0011-encrypted-versions-and-private-links.md).

Сплошное скрытие заменяет пиксели чёрным в сохранённом JPEG. Слои остаются доступными авторизованной команде для редактирования оригинала, но внешний файл содержит только итоговые пиксели. Получатель никогда не получает исходник или возможность отключить маску. Blur/pixelation не предлагаются как необратимая защита.

`view` убирает кнопку скачивания, но не мешает получателю сохранить уже показанные пиксели или сделать скриншот. Отзыв и TTL запрещают новые API-чтения сразу; открытый просмотр перепроверяет доступ раз в 10 секунд и скрывает снимок при отказе, скачивание перепроверяет отдельно. Ранее полученную копию отозвать нельзя. TTL parent и актуальный shareExternal grant издателя проверяются на каждом чтении. Ссылки не продлевают жизнь снимка, не используют public bucket/presigned S3 URL. Revocation сначала закрывает доступ, затем удаляет отдельный export; scheduler повторяет очистку. Все дочерние ciphertext входят в квоту и существующий verified delete оригинала.

## Проверка

`check-editor-sharing.mjs` создаёт синтетические аккаунты, проверяет UI маски и пиксели JPEG получателя, cloud/new-device read, конфликт, encrypted offline draft/retry, внешний анонимный просмотр, отсутствие ключа в запросах, неверный fragment, scope, revoke и сокращение TTL родителя. Строгий runtime monitor не выводит ключи, фото или bodies. API tests проверяют idempotency, неизменность родителя, коррупцию, квоту/чужой аккаунт, отдельность share export, expiry/revoke и физическую очистку. WebCrypto tests проверяют AEAD tamper/AAD/wrong-key/expiry.

Это локальный стенд. Реальные телефоны, memory pressure больших экспортов, полный offline PWA, независимое security review и production release остаются R01.

Локальная проверка 16 октября 2026: 83 API tests / 1309 assertions, 103 client tests, Pint 97 files, TypeScript/build и private/signed S3 прошли. B05, командные сценарии и обязательный вход/whole-app PIN проверены в Chromium/WebKit. Проверка масок включает 16 сочетаний quarter-turn/mirror/crop на каждом engine. Реальные телефоны и production не объявлены проверенными.
